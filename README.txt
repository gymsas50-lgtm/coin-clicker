NEW GAME - MULTIPLAYER SERVER

Windows 10/11, internet required for first launch.

ONE-TIME UPGRADE:
1. Close the old server window (port 3000 must be free).
2. Extract this complete ZIP to a NEW folder.
3. Run Clicker/START.bat.
4. First launch downloads a portable Node.js runtime from nodejs.org.
   No administrator rights or system Node.js installation needed.
5. Allow Node.js through Windows Firewall on PRIVATE networks.
6. Open the printed Phone address on devices connected to the same network.

KEEP THE SERVER WINDOW OPEN.
Do not run the previous server at the same time.

UPDATES:
The launcher checks GitHub every 8 seconds.
Both index.html and server.js are updated automatically.
Server code updates briefly restart the server and clients reconnect.
If GitHub is unavailable, the last downloaded game continues working.
The bootstrap server.ps1 and Node.js runtime are not self-updated.

MULTIPLAYER:
WASD / arrow keys on PC. Touch joystick on phones.
All players using this server share one map.
The dot marks your own character. Player colors are assigned at connection.
No accounts, saved positions or public-internet hosting yet.
Server capacity: 100 connections; actual performance depends on the PC/network.
Do not expose this prototype directly to the public internet.

ARCHIVE:
The previous coin game is preserved separately, not launched by this package.

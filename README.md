# First-person camera prototype

Node.js 22 server with LAN access and the existing Windows auto-updater.

The client is self-contained: Three.js, a procedural photographic camera, two first-person hands and a neutral test studio.

Click Start to capture the mouse. WASD moves, Shift runs, left click (or F) saves a PNG photo without the viewmodel or UI. Escape releases the cursor.

Run `npm start` or `START.bat` on Windows. Port 3000 by default, configurable with `PORT`. The old mining game is not included.

The legacy app-id remains for compatibility with existing launchers.

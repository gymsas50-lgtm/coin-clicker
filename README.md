# Пустой мир — автомобиль

Новый самостоятельный проект: пустая 3D-площадка и управляемый автомобиль.
Старые сундук, ключи, валюта, добыча, Roblox-проект, EXE-оболочка и автообновление удалены из текущего проекта.

## Запуск

Открой `index.html` в современном браузере. Игра полностью автономна: Three.js, физика и все материалы встроены в HTML, интернет не требуется.

Или выполни `npm start` и открой `http://localhost:3000`.
`serve.cjs` — только статический сервер, без проверки обновлений и без фоновых загрузок.

## Управление

- WASD / стрелки — газ, задний ход, поворот.
- Пробел — тормоз.
- R или кнопка «На старт» — сброс положения машины.
- На сенсорном экране — кнопки управления.

Камера автоматически следует за автомобилем. Физика cannon-es: масса, подвеска, сцепление, торможение, инерция. Фиксированный шаг 120 Гц; отрисовка через requestAnimationFrame без ограничения 30/60 FPS. Скорость в км/ч показана справа снизу. При потере фокуса игра ставится на паузу и сбрасывает нажатые кнопки.

## Сборка

`npm install` → `npm run build`.
Исходники: `src/game.js` и `src/page.html`.
Three.js 0.180.0 и cannon-es 0.20.0, MIT; лицензии в `src/` и внутри HTML.

Текущая версия: v0.1.0. Нет трафика, зданий, препятствий, валюты и инвентаря — только базовое вождение в пустом мире.

# Кликер для iPhone

Игра и домашний сервер Windows с автоматическими обновлениями.

## Установка
1. Скачайте [server-windows.zip](https://github.com/gymsas50-lgtm/coin-clicker/raw/refs/heads/main/server-windows.zip).
2. Полностью распакуйте архив, закройте старый сервер, запустите `START.bat`.
3. Откройте адрес домашнего ПК на порту 3000 в Safari на телефоне.

Сервер получает `index.html` из этого репозитория. При изменении файла
страница перезагружается автоматически. При недоступности сети остаётся
локальная версия. Компьютер должен быть включён, телефон — в домашней сети.
Не публикуйте сервер напрямую в интернет.

Сохранения остаются в браузере пользователя и не передаются в GitHub.
В игре есть запрошенный одноразовый сброс прогресса; он не повторяется
после первого применения в том же браузере.

`index.html` — страница с JavaScript, а не сайт для просмотра через Raw.
Для игры используйте домашний сервер, либо отдельно включите GitHub Pages.
